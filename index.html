Welcome to My Website

This website was created as part of my web development course. It demonstrates the use of external CSS for styling, consistent design across pages, and proper separation of content and presentation.

Learning HTML and CSS has been an exciting process. I have applied element selectors, class selectors, color schemes, and typography to make the site readable and visually appealing.

Explore the other pages to learn more about this project and find helpful resources for web development.

Note: All styling is handled through the external stylesheet at css/styles.css. No inline styles are used.
