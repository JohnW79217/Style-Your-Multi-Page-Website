About the Website

This multi-page website was built to practice core web development skills. It continues from previous assignments and focuses on adding professional CSS styling.

The site uses a consistent color scheme and typography so that all pages feel like part of the same website. Navigation is simple and clear, and links are styled to stand out from regular text.

What I Learned

I practiced creating an external stylesheet, using multiple element selectors, applying class selectors, choosing readable colors, and setting font properties.

One challenge was ensuring the CSS path worked correctly on all pages. I solved it by using a consistent relative path: css/styles.css.

The primary goal of this assignment was to add CSS while keeping the HTML clean and semantic.
