Learning Resources

Here are some of the best free resources I used while learning HTML and CSS for this project:

  • MDN Web Docs - HTML
  • MDN Web Docs - CSS
  • W3Schools HTML Tutorial
  • W3Schools CSS Tutorial
  • CSS-Tricks
  • GitHub Pages Documentation

These sites helped me understand selectors, the cascade, and best practices for accessible color contrast.

Tip: Always test your website in a browser before submitting. Check that links work, images load, and CSS is applied correctly.

Why These Resources?

MDN is the most reliable reference for web standards. W3Schools is beginner-friendly with interactive examples. CSS-Tricks has excellent articles on modern techniques. GitHub Pages made it easy to publish this site for free.
